# 桌面宠物市场调研

## 主流产品分析

### Desktop Goose (samperson, 2020)
- **技术栈**: C# + WPF
- **渲染**: 2D 精灵图动画
- **特色**: 混乱型宠物——拖拽表情包、偷鼠标、留脚印、干扰用户
- **模式**: 免费/pay-what-you-want (itch.io)
- **启示**: 病毒式传播，"捣乱"比"可爱"更有传播力

### Shimeji (日本, 长期项目)
- **技术栈**: Java (Shimeji-ee) / 浏览器扩展
- **渲染**: 2D 精灵图动画
- **特色**: 多角色、可攀爬窗口边缘、社区自制角色
- **模式**: 开源免费
- **启示**: 高度可定制性是核心吸引力，社区生态很重要

### Desktop Mate (2024-2025)
- **技术栈**: Unity (推测)
- **渲染**: 2D/3D 混合
- **特色**: 虚拟伴侣型，AI 对话能力
- **模式**: 商业化
- **启示**: AI 集成是新趋势，伴侣型比单纯动画更有粘性

### 系列产品趋势
- **Wallpaper Engine**: 动态壁纸 + 桌面小部件，Steam 平台，用户生成内容生态
- **VTuber 桌面伴侣**: Live2D 驱动的虚拟形象桌面应用
- **AI 桌面助手**: 集成 LLM 的桌面宠物/助手融合产品

## 用户需求分析

### 核心需求
1. **陪伴感**: 桌面上有一个"活着"的存在
2. **互动性**: 能响应用户操作（点击、拖拽、语音）
3. **个性化**: 可更换外观、性格、行为
4. **不干扰**: 可以在需要时隐藏或静音
5. **功能性**: 不只是装饰，要有实际用途

### 高频期望功能
- 天气显示、日程提醒
- AI 对话/聊天
- 番茄钟/专注模式
- 系统监控（CPU/内存/网速）
- 小游戏/互动
- 音乐可视化
- 翻译/查词

## 市场定位建议

| 定位 | 目标用户 | 差异化 |
|------|---------|--------|
| AI 伴侣型 | 年轻用户、独居人群 | LLM 集成、情感交互 |
| 生产力型 | 职场/学生 | 番茄钟、日程、提醒 |
| 娱乐型 | 泛用户 | 小游戏、梗图、社交分享 |
| 创作者平台型 | 开发者/创作者 | 插件市场、UGC 生态 |

**推荐定位**: 创作者平台型 + AI 伴侣型——以插件架构为核心，内置 AI 对话作为杀手级功能，开放插件市场形成生态。
